# Day Summarizer 🎥

Desktop application that captures screenshots or short screen recordings at fixed intervals throughout the day and automatically generates a summary video from all captured moments.

**You need to have FFMPEG installed**

![](https://cdn.hackclub.com/019ea168-a0c6-79e7-a896-c39ad34693c5/image.png)

---

## ✨ Features

- 📸 Automatic screen screenshots or recordings
- ⏱️ Configurable capture interval (minutes/hours)
- 🎤 Optional microphone capture
- 🖥️ Optional desktop audio capture
- 🕒 Auto-stop at a defined time
- 🎞️ Automatic slideshow/video generation from captures

---

## 🚀 How it works

1. The app runs in the background
2. Captures the screen at a fixed interval
3. Stores each capture locally
4. At the end of the fixed time:
   - All images/videos are combined
   - A final summary video is generated
