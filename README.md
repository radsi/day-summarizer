# Day Summarizer 🎥

Day Summarizer is a desktop application that captures screenshots or short screen recordings at regular intervals and automatically generates a summary video from the collected captures. It supports configurable intervals, optional microphone and system audio recording, automatic stop times, and background execution through the system tray.

**You need to have FFMPEG installed**
